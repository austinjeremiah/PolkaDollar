## Available Functions

### Vault Operations

```typescript
// Deposit DOT
await depositCollateral('1.5');  // Deposits 1.5 DOT

// Get collateral amount
const collateral = await getCollateral(userAddress);  // Returns: "1.5"
```

### pUSD Operations

```typescript
// Mint pUSD
await mintPusd('100');  // Mint 100 pUSD

// Burn pUSD
await burnPusd('50');   // Burn 50 pUSD

// Get balance
const balance = await getPusdBalance(userAddress);  // Returns: "100"
```

### Price Feed

```typescript
// Get current DOT price
const price = await getCurrentPrice();  // Returns: "1.61"
```

### XCM Bridge

```typescript
// Send custom XCM message to Hydration
const messageHex = "0x0414000400...";  // Generated by `pnpm xcm:encode`
await sendXcmToHydration(messageHex);
```

### Utility

```typescript
// Switch/add network in MetaMask
await switchNetwork();
```

## Example Component

```typescript
'use client';

import { useState } from 'react';
import { usePolkadollarBackend } from '@/hooks/use-polkadollar-backend';

export function DepositForm() {
  const [amount, setAmount] = useState('');
  const { depositCollateral, loading, error } = usePolkadollarBackend();

  const handleDeposit = async () => {
    try {
      const { hash } = await depositCollateral(amount);
      console.log('Deposit submitted:', hash);
      setAmount('');
    } catch (err) {
      console.error('Deposit failed:', err);
    }
  };

  return (
    <div>
      <input
        type="number"
        value={amount}
        onChange={(e) => setAmount(e.target.value)}
        placeholder="Amount in DOT"
        disabled={loading}
      />
      <button onClick={handleDeposit} disabled={loading}>
        {loading ? 'Depositing...' : 'Deposit DOT'}
      </button>
      {error && <p style={{ color: 'red' }}>{error}</p>}
    </div>
  );
}
```

## Troubleshooting

### No wallet connected
- Ensure MetaMask is installed
- Ensure you're on the right network (Polkadot Hub TestNet, Chain ID 420420417)

### Transaction reverted
- Check if you have enough DOT for gas
- Check vault collateralization ratio
- Check PriceFeed has been updated recently

### XCM message failed
- Ensure message bytes are valid (use `pnpm xcm:encode`)
- Ensure precompile is at `0xA000`
- Check Hydration is receiving messages
